# AlchyMastery

AlchyMastery is an alchemy mod for NeoForge (Minecraft 26.1.2). You tear reality open, hold the distortion in a chamber, and use it to run the alchemical cycle: break matter down into compounds, transmute them into other matter, and rebuild them into ores and ingots.

Every machine is a multiblock chamber built from ordinary blocks around a core. When the structure is right, the core remakes it into the machine.

## Requirements

- NeoForge 26.1.2
- [AlchyX](https://github.com/JustAlex14/AlchyX) (the multiblock library, required)
- Optional: Patchouli (the Alchemist's Codex), JEI (recipes), Jade, Curios (the experience siphon as a charm)

## The Alchemist's Codex

With Patchouli installed, craft a book with an amethyst shard to get the Alchemist's Codex. It is the in-game guide, written as the journal of the alchemist who found the tear. Its chapters open one after the other, and every machine page can **Visualize** the structure as ghost blocks where you look.
