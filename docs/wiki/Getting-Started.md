# Getting Started

## How machines work

Every machine is a chamber: ordinary blocks around a core (the catalyst). Place the core, build the frame around it, and when the last block is right the core remakes the frame. Blocks change their look, glass may vanish, fires turn blue. From then on:

- Right-click the core or any block of the frame to open the machine.
- Hoppers and pipes work on any block of the frame.
- Break any block of the frame and the chamber collapses. The frame is lost, only the core survives (with its upgrades).

Right-clicking a core before the chamber is formed opens its screen with a **Show structure** button. Ghost blocks show what is missing and red dust marks what is wrong. The Codex's **Visualize** button does the same from the book.

A core that faces you when placed turns the whole chamber with it, so every machine can be built in any direction.

## The order of things

Each step needs the one before it.

1. **Codex.** Book and amethyst shard (needs Patchouli).
2. **Distortion Matrix and Distortion Chamber.** The matrix burns lapis into distortion energy (DE) inside the chamber. See [Distortion Energy](Distortion-Energy).
3. **Distortion Crystal.** It goes on the chamber's roof. No chamber forms without one.
4. **Wormholes and the Wormhole Attuner.** Every other machine takes its energy through a wormhole linked to a chamber up to 124 blocks away.
5. **Distortion Condensator.** Turns water into distortion fluid.
6. **Distortion Shards** (a bucket of distortion fluid soaks four amethyst shards) and the **Alchemical Lattice** (shards and gold in blackstone). Every later core is made from a lattice.
7. **Destructuration Chamber.** Breaks items down into compounds.
8. **Transmutation Chamber.** Turns compounds into other compounds of the same family.
9. **Reconstruction Chamber.** Rebuilds compounds into items.
10. **Rendering Cauldron.** Turns mob essences into liquid experience.
11. **Upgrades**, then the **Nexuses**, which fold whole chambers into one machine.

## The cycle

A typical loop: put iron ore in the Destructuration Chamber and get iron compounds. Set the Transmutation Chamber's target to gold and feed it the iron compounds. Put the gold compounds, distortion fluid and a base block in the Reconstruction Chamber and get gold back as raw ore, ingots or ore blocks.

Value is kept through the cycle, minus a loss when transmuting between tiers. See [Compounds](Compounds).
